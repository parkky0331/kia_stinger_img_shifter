# Stinger Image Shifter

[English](README.en.md)

스팅어(CK PE) 순정 내비게이션에서 드라이브 모드를 바꾸면 나오는 차량 그림을, 예전 인포테인먼트에서 쓰던 스팅어 투시도로 바꿔 주는 [HMG-API](https://github.com/Open-HMG/HMG-API) 모드입니다.

지금 순정은 모드를 바꾸면 검은색 일반 세단 그림이 나옵니다. 구형에서는 스팅어 투시도가 모드 색에 맞춰 나왔는데, 그 그림을 다시 쓰고 싶어서 만들었습니다.

## 바뀌는 곳

- 지도 화면 오른쪽 패널, 그리고 모드를 바꿀 때 그 자리에 뜨는 팝업
- 차량 설정 > 드라이브 모드 화면의 안내 그림 속 작은 차
- 차량 설정의 모드 변경 팝업 (테스트한 차량에서는 이 팝업이 뜨지 않아 확인하지 못했습니다)

스마트, 에코, 컴포트, 스포츠, 커스텀 다섯 가지 모드의 그림이 바뀝니다.

모드 안에 순정 그림은 들어 있지 않습니다. 투시도와 모드별 바닥 그림은 차에 이미 들어 있는 것을 꺼내 쓰고, 순정 파일은 하나도 건드리지 않습니다. 모드를 끄면 바로 순정 그림으로 돌아옵니다.

## 필요한 것

- Gen5W 내비게이션이 달린 스팅어(CK PE). 다른 차에는 HMG-API가 설치를 막습니다.
- HMG-API 1.0.2 이상

## 설치

1. [릴리스](https://github.com/parkky0331/kia_stinger_img_shifter/releases)에서 `stinger-imgshifter-<버전>.zip`을 받아 USB의 `HMGAPI/updates/` 폴더에 넣습니다. 압축은 풀지 않고 zip 파일 그대로 넣습니다. USB 안은 이런 모양이 됩니다.

   ```
   USB
   └── HMGAPI
       └── updates
           └── stinger-imgshifter-0.1.0.zip
   ```

2. HMG-API 앱에서 Check USB updates → 설치 → Apply changes → Restart unit 순서로 누릅니다.
3. 테스트 중인 카메라 화면 차량 색은 HMG-API 앱의 Mods 탭에서 이 모드의 설정을 열어 고릅니다. 바꾼 뒤에는 Restart unit을 한 번 더 해야 적용됩니다.

순정으로 돌리고 싶으면 Mods 탭에서 끄면 됩니다.

## 테스트한 차량

개인 소유 차량 한 대에서만 테스트했습니다(펌웨어 `CK_PE_22.KOR.S5W_M.V039.001.260902`). 펌웨어가 다르면 그림 이름이나 자리가 다를 수 있는데, 그럴 때는 건드리지 않고 순정 그대로 둡니다.

<details>
<summary><b>테스트 중: 카메라 화면의 차량을 내 차 색으로 보기</b></summary>

카메라(어라운드뷰) 화면에 나오는 차는 실제 차 색과 상관없이 은색입니다. 설정에서 색을 고르면 카메라 화면이 떠 있는 동안 이 차를 고른 색으로 보여 줍니다. 기본은 "끄기"이고, 그대로 두면 카메라 앱에는 아예 손대지 않습니다.

화면의 차는 헤드유닛에 있는 그림이 아니라 카메라 장치가 영상에 직접 그려 넣는 그림입니다. 그래서 색만 바꿀 수는 없고, 같은 자리에 고른 색의 차를 덧씌워서 보여 줍니다. 카메라 영상 자체는 건드리지 않습니다.

색은 스팅어 출고 색상 중에서 고릅니다. 스노우 화이트 펄, 오로라 블랙 펄, 판테라 메탈, 세라믹 실버, 하이크로마 레드, 딥 크로마 블루, 마이크로 블루, 네온 오렌지, 에스코트 그린, 문스케이프 매트 그레이가 있습니다. 화면에서 비슷해 보이도록 맞춘 값이라 실제 도장과는 조금 다를 수 있습니다.

아직 다듬는 중이라 아래 내용은 알고 쓰셔야 합니다.

- 덧씌우는 자리와 크기는 테스트 차량의 화면을 사진으로 찍어서 잰 값입니다. 차량에 따라 몇 픽셀 어긋나 보일 수 있습니다.
- 후방 화면 세 가지와 전방 화면 세 가지에서 나옵니다. 오른쪽 탑뷰의 차를 덮고, 차를 위에서 내려다보는 화면에서는 왼쪽에 크게 나오는 차도 같이 덮습니다. 화면 선택 버튼에 있는 작은 차도 같은 색으로 칠합니다.
- 탑뷰를 축소하면 순정 차가 작아지는데, 그 크기는 아직 재지 못했습니다. 지금은 한 단계에 5%씩 줄여서 보여 줍니다.
- 덧씌운 차는 순정 차 위로 0.5초에 걸쳐 서서히 나타납니다. 화면이 꺼지거나 다른 화면으로 넘어갈 때는 새 영상을 가리지 않도록 바로 사라집니다.
- 화면이 꺼질 때 덧씌운 차가 영상보다 아주 잠깐 늦게 사라질 수 있습니다. 이걸 줄여 보려고 "차량을 따로 그리기" 설정을 넣어 뒀는데 아직 차에서 확인하지 못했습니다. 켰을 때 차가 안 보이거나 화면이 이상하면 끄면 됩니다.
- 어라운드뷰가 없는 차량은 주차 센서 표시 사이의 차 그림을 같은 색으로 칠하게 해 뒀는데, 그런 차량에서는 테스트해 보지 못했습니다.
- 덧씌우는 차는 스팅어 공식 그림이 아닙니다. 제가 AI로 생성해서 따로 만든 그림입니다.

</details>

<summary><b>동작 방식</b></summary>

- 순정 앱이 화면에 그림을 올리는 순간(`ImageView.setImageResource`, 설정 앱은 `View.setBackgroundResource`)에 끼어들어서, 드라이브 모드 그림일 때만 다른 그림을 건네줍니다. 나머지 그림은 그대로 지나갑니다.
- 그림 재료는 차량 설정 앱에 들어 있는 것을 실행 중에 읽습니다. 모드별 바닥 그림 위에, 스팅어 투시도를 모드 색으로 칠해서 올립니다.
- 예전 바닥 그림의 실제 크기가 오른쪽 패널 그림과 같은 600×330이라, 패널에서는 확대나 축소 없이 픽셀 그대로 나옵니다. 설정 팝업은 1.6배로 키워야 해서 먼저 빠르게 키운 그림을 보여 주고, 뒤에서 선명하게 다시 만든 그림으로 바꿉니다.
- 안내 그림은 순정 그림을 복사한 뒤 작은 차가 있는 칸만 다시 그립니다. 그림 틀이 예상한 자리에 없으면 건드리지 않습니다.
- 카메라 화면의 차는 영상 위에 그림 한 장을 얹어서 보여 줍니다. 화면 선택 버튼 같은 헤드유닛 그림은 은색 차체 부분만 골라 칠하고, 유리, 램프, 그림자는 그대로 둡니다.
- 그림은 앱이 뜬 뒤 뒤에서 미리 만들어 둡니다. 아직 준비가 안 됐는데 그림이 필요해지면 그 한 번은 순정 그림이 나옵니다. 카메라 앱이 모드 때문에 기다리는 일은 없습니다.
- 모드가 꺼져 있거나 재료가 없거나 그림을 못 만들면 순정 그림이 그대로 나옵니다.
- 순정 파일을 바꾸지 않고, 차에 신호를 보내지 않고, 네트워크도 쓰지 않습니다.

</details>

<details>
<summary><b>직접 빌드하기</b></summary>

JDK, Android API 19의 `android.jar`, Android SDK build-tools(d8), 그리고 HMG-API 소스가 필요합니다.

```sh
export HMG_API=/path/to/HMG-API
export ANDROID_JAR=/path/to/Android/sdk/platforms/android-19/android.jar
export D8=/path/to/Android/sdk/build-tools/35.0.0/d8
export SIGNING_KEY=/absolute/path/to/your.key
sh build.sh        # dist/stinger-imgshifter-<버전>.zip
```

같은 값을 `build.sh` 옆의 `local.env` 파일에 적어 둬도 됩니다(git에는 올라가지 않습니다). 서명 키는 HMG-API의 서명 도구로 각자 만들어야 합니다. HMG-API는 같은 키로 서명한 패키지로만 모드를 업데이트합니다.

검사는 두 가지가 있습니다.

```sh
sh tools/check.sh             # 이름, 색 입히기, 크기 조절, 차체 색. 빌드할 때도 같이 돕니다
bash tests/harness/run.sh     # 에뮬레이터에서 순정 그림과 바뀐 그림을 나란히 확인
```

`tests/harness/run.sh`는 본인 차에서 꺼낸 순정 앱 세 개(`HKMC_VehicleSetting.apk`, `RightScreenHome.apk`, `HKMC_RearCamera.apk`)가 있어야 돌아갑니다. 순정 앱과 그림, 헤드유닛에서 꺼낸 파일은 이 저장소에 올리지 않습니다.

</details>

<details>
<summary><b>로그 보는 법</b></summary>

HMG-API 로그에 `[stinger-imgshifter]`로 남습니다.

- `ready in <프로세스>`: 그 앱에 훅이 들어갔습니다
- `sees <그림 이름> <크기>: …`: 그 이름의 그림을 처음 봤습니다. `left as it is`가 붙으면 건드리지 않은 것입니다
- `made … in N ms`: 그림 하나를 만드는 데 걸린 시간
- `shows ours for <그림 이름>`: 그림을 바꿔서 보여 줬습니다
- `<그림 이름> was asked for before its picture was ready`: 준비 전이라 그 한 번은 순정 그림이 나갔습니다
- `camera screen started: RearMode | AvmMode | AvmModeLowCam`: 카메라 앱의 어느 화면이 떴는지
- `surround view: …`: 카메라 화면 차량 색을 골랐을 때, 카메라 장치가 알린 화면과 덧씌운 차의 상태

</details>

## 알아 둘 점

- 설정 팝업 그림은 원본(649×302)을 1.6배 키운 거라 조금 흐릴 수 있습니다.
- 드라이브 모드 안내 그림은 새 안내 그림(`usm_dm_008_01_n_…`)을 쓰는 헤드유닛에서만 바뀝니다.
